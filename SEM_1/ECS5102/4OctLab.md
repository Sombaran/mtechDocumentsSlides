# 4 October 2025 (Block chain proof of work)

## Definition

- Digital ledger secures transaction across peer to peer network
- Every member has equal right in decision making
- An advanced DB mechanism that allows transparent information sharing within a business network
- Stores data in blocks that are linked together in a chain
- Breaking chain is not possible, nor delete or modify the chain withour consensus from the network
- Creates an immutable or unalterable ledger for tracking order, payment, account and other transaction 
- For eg: A consultancy org 

## Properties

- Smart contract: Auto execution of digital signature
- Secured: All records are individually encrypted
- Trusted: De-centralized: control is with multiple stakeholder
- Consensus: All stakeholder agree to the validity of each of the record
- Distributed: All stakeholder have a copy of the ledger for complete transaparency
- Immutable: Any validated records are irreversible and cannot be changed
- Timestamped: Is recoreded for each block

## How does it work

- A new transaction is entered
- Transaction is transferred to a network of peer-to-peer computers scattered across the world
- The network then validates the transaction by solving equations by network of computers
- Once validity is confirmed the transaction is then clustered into the block of chain 
- This block of chain is now availble for all reference and get attached at the end
- Transaction finished

## Is there any limitation as number of blocks? No.
